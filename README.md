# Rajeswaran Gajendran — Embedded Software Portfolio

A responsive, static portfolio built with plain HTML, CSS, and JavaScript. It has no build step and no external dependencies.

## Files
- `index.html` — page content
- `styles.css` — responsive dark navy styling
- `script.js` — mobile navigation, active section highlighting, copy-email interaction
- `assets/Rajeswaran_Gajendran_Resume.pdf` — résumé supplied for this portfolio

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use a small local web server or VS Code Live Server.

## Publish with GitHub Pages
1. Sign in to GitHub and create a repository named `rajeswaran-portfolio` (or another available name).
2. Upload the contents of this folder to the repository root. Keep the `assets` folder.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment and open the URL shown in Settings → Pages.
